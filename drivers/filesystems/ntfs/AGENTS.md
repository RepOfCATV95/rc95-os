## RC95-OS NTFS Driver

RC95-OS NTFS is a filesystem driver for RC95-OS.

This file serves as a guide for future NTFS commits.

## Source of Truth

## Code style
- Keep coding style (must be 4-space indentation, long lines must be encased with braces) in existing and new files.

## Changes and commits

- Use "[NTFS] <gitmessage>" for wholescale changes. If commit does not speak for itself, always follow AGENTS.md in top-level directory and use
"Problem:", "Why:" and "How:" in paragraphs separated by blank lines. Also, number of commits made through AI tool must not exceed 150.
